This page is normative and defines ADM semantics.

# Tutorials

## Purpose
Tutorials explain how to read and apply existing ADM semantics without redefining them.

## Tutorial Set
1. Identify the correct ADM layer for an architectural statement. Practised in [Worked Examples]({{ site.baseurl }}/worked-examples/).
2. Verify layer discipline for vertical and horizontal layers. Practised in the Star Rangers case study's [Violations]({{ site.baseurl }}/case-studies/star-rangers/#violations-historical-since-corrected) section.
3. Validate that derived artifacts do not redefine ADM semantics. Practised in [ADM and C4]({{ site.baseurl }}/adm-and-c4/).

## Non-Negotiable Rules for Tutorials
- Tutorials MUST reference existing ADM definitions.
- Tutorials MUST NOT introduce new ADM semantics.
- Tutorials MUST NOT collapse, merge, or skip layers.
